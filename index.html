Prompt2App Sandbox

Prompt → Web App Gallery

A public collection of prompts — some written up front, some reverse-engineered from a finished app — that you can paste into any model, hosted or local, to generate or remix the web app yourself. Each entry pairs a live demo with the exact prompt text behind it, so you can compare what your model produces.

Open a prompt
Pick an app below and read or copy its prompt (.md) file.
02
Run it on your model
Paste it into Claude, GPT, Gemini, or a local model (Llama, Mistral, Qwen...).
03
Compare results
Check the included live demo to see the reference build side by side with yours.

Open an app's .html file directly, or serve this folder over GitHub Pages / a local static server to click straight through.
